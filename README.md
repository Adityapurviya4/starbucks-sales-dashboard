**Starbucks Sales Manager — Interactive Analytics Dashboard**
> 
> An interactive web dashboard built to visualize 6 months of Starbucks POS transaction data (149,116 rows) alongside an interactive 3D coffee cup model.
> 
> 
> **Key Features:**
> * **Zero-Backend Architecture:** Fully self-contained in a single `.html` file with no external database or server required.
> 
> 
> * **Ultra-Compressed Payload:** Custom binary buffer packing and `gzip` compression shrink 150k transaction rows (~125 KB) and a 14.8 MB 3D GLB model (<4.2 MB) directly inside the browser payload.
> 
> 
> * **Instant Dynamic Filtering:** Real-time client-side data re-aggregation across stores, product categories, sizes, hours, weekdays, and date ranges without page reloads.
> 
> 
> * **Interactive 3D Experience:** Three.js-powered 3D cup with drag-to-rotate, inertia, pulse animations, and a responsive scroll-docking canvas.
